# Scale-Claim-Triage

Prototype claims agent dashboard for an auto insurance claims triage system.

## Run

Open `index.html` in any modern browser. No build step.

## Layout

- **Sidebar:** claims queue grouped by routing decision (Awaiting Agent Review / Auto-Resolved / Escalated to Senior Adjuster).
- **Main panel:** claim detail with damage photo, structured assessment, confidence breakdown, and accept/override actions.
- **Audit log tab:** historical agent decisions on model recommendations.

Three sample claims are hardcoded; CLM-2024-001 is selected by default.
